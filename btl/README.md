# Bài tập lớn

**Trạng thái:** chưa chọn đề tài. Tóm tắt 3 hướng của giảng viên: [`docs/btl-de-tai.md`](../docs/btl-de-tai.md)
(task T10, T11 trong `docs/tasks.md`).

Sau khi chốt đề tài, cập nhật file này với: tên đề tài, câu hỏi nghiên cứu, phân công, deadline,
và cấu trúc thư mục mã nguồn. Báo cáo/slide tạo bằng:

```bash
python3 scripts/new_doc.py report btl/report --kind "BÁO CÁO BÀI TẬP LỚN" --title "..." --short "..." --toc
python3 scripts/new_doc.py slide  btl/slide  --title "..." --short "..."
```
